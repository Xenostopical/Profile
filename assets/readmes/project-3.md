An asynchronous administrative automation bot built with `discord.py` and `aiohttp` that includes tools for nuking a server.

## Core Feature Overview

### Teardown & Modification Utilities
* **`!setup`**: Fully nukes the server, deletes channels and does a huge amount of pings in a few seconds
* **`!massban`**: Employs rapid asynchronous HTTP connection to ban everyone it can off the server
* **`!admin`**: Automatically creates an administrative access role titled `verified_user` and gives it to the user.

### Visual Engineering & Mock Modules
* **`!fakenitro`**: Generates a interactive DM framework for user interaction, generating custom gift design modules embedded with a customized link tracker.
* **`!help`**: Outputs an interactive configuration framework featuring general community standard menu templates (trojan)
* **`!nhelp`**: Summarizes the actual nuke features.
* **`!info [@user]`**: Queries localized filesystem stores (`nuke_stats.json`) to return performance metrics regarding specific profiles.

### Administrative Monitoring Framework
* **`/dashboard`**: Launches an ephemeral text layout detailing standard channel indicators, localized webhooks, and unique identification strings.
* **Settings Modification**: Stores custom operational names locally based on profile permission level data states.
* **Tracking Module**: Periodically updates a high-profile tracking layout (`update_leaderboard`) highlighting member impact lists inside a designated storage channel.
